Radio Atlas — reference terminal UI

Full-app target for the Textual terminal build, drawn on a character grid (1 column = 1ch, 1 row = one terminal line). The browser artboard previews icons with inline SVG; the terminal app emits Font Awesome private-use glyphs from a user-selected Nerd Font. The app stays a terminal app.

Try it: click a tab, a row star or the transport star to toggle favorites, click the volume bar to set the level, press the pause pill to toggle play. Click targets map to existing Textual click handlers.

Use a Nerd Font in the terminal's font settings; Radio Atlas will not install a font or edit terminal configuration. Without it, private-use glyphs can show tofu. --ascii uses the explicit ASCII aliases. Notices: connectivity remains in the header; errors also remain inline. Narrow footers drop chips by priority: space, q, ?, /, f, 1, 2, 3, r, c, 4.
