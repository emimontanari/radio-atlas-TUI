Tradeoff and native scope

Strongest distinction between selection and playback, with room for full selected names. Costs the most layout change and reduces the globe’s prominence. The selected summary is a proposal using existing station metadata, not a new data source.

Terminal-grid prototype, never a web replacement. Reuse charcoal/lavender styling; green ● LIVE is the proposed new playing-only accent. Paused shows “Paused”; errors show the failure, never LIVE. Empty lists have no selected station and show “No stations match · Esc Back”. Cell-based controls keep terminal font ownership intact.
