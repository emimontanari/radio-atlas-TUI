Tradeoff and state rules

Longest readable names and a consistent vertical order, but fewer station rows and a much smaller globe. Empty results occupy one clear “No stations match” row; selection is absent and Esc returns to the prior view. Playing alone shows the proposed green ● LIVE accent; paused shows “Paused”.

Terminal-grid visual prototype only. Use Textual cell dimensions, not per-widget font scaling. Reuse charcoal/lavender project appearance and existing keyboard actions; no new navigation or web frontend.
